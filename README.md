# 薪火志内容补充 / Contribute to The Flame Journal

这里收集中国非遗相关的内容补充、事实纠错和官方资料线索。网站：https://xinhuozhi.org

**请通过 Issues 的“内容补充或纠错”表单投稿。Issue正文及附件会公开可见，请勿提交只允许私下核验的材料。这里不是网站代码仓库；投稿不会直接修改或发布网站。**

## 投稿要求

- 只接受中国非遗相关内容，不收录其他国家的非遗项目。
- 所有事实来源必须是中国官方机构的网站原文。外国网站、百科、商业网站、自媒体、搜索摘要和AI回答不作为事实来源。
- 填写发布机构、原文链接、资料日期，以及该来源支持的具体说法。网站使用中文或 `.cn` 域名，并不能单独证明它是中国官方网站。
- 新增内容必须符合[内容标准](CONTENT_STANDARD.md)。不把文化项目认定当成商品、制作者或当前活动的认证。
- 图片、音乐、视频和文章能在网上打开，不等于可以转载；没有明确许可的素材只提供中国官方原页线索，不上传文件。

阅读[投稿说明](CONTRIBUTING.md)，然后在本仓库的 Issues 页面选择“New issue”。更正既有页面时请附薪火志页面链接。

## 投稿之后

编辑先核官方身份和原文，再审事实、权利及中英文表述。资料不足会要求补充或不予采用。只有完成审校的内容，才由薪火志总控整合进内部唯一工程，经过测试和页面验收后发布。收件、讨论、关闭Issue均不等于已采用或已上线。

网站源代码、部署凭证、内部审校记录和发布权限不在本仓库。请不要通过 Pull Request 提交网站修改；本仓库只接受内容线索，维护者自行维护投稿规范。

## English

This repository collects additions and corrections about Chinese intangible cultural heritage. Submit an issue using the structured form. It does not contain the website's source code and submissions cannot change or deploy the site.

Every factual source must be an original page on a verified Chinese official institution's website. Sources from outside China and heritage subjects from other countries are outside this collection's scope. A Chinese-language page or a `.cn` domain alone is not proof of official status. Unsupported claims, search snippets and AI-generated citations are not accepted.

Editors verify the evidence and permissions before preparing independently written Chinese and English content. Acceptance and website publication are separate steps. Issues and attachments are publicly visible. Do not post material intended only for private review. Do not upload unlicensed third-party media. Never submit credentials or private personal information.

## 权利

公开投稿不代表全站或全部投稿采用开源许可。本仓库不采用代码MIT许可或全站CC BY；每份原创文字与素材的使用范围分别确认。仅供核验的资料不会因此被视为已授权转载。投稿者请在表单说明是否允许薪火志编辑并公开展示其原创文字。
