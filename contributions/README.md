# 内容候选目录

这里接收可供审查的资料线索、纠错和原创草稿。每个候选使用 `contributions/<地区ID>/<候选ID>.md`，每批最多两个专题。跨省对象引用同一项目，不因名称相近合并。

按以下顺序组织，未知项直接写未知：

1. **标题**：对象、地区、涉及的本站页面或稳定ID、希望解决的问题。
2. **骨架**：拟新增或修正的部分、项目／人物／认定关系、来源清单、未决项。
3. **内容**：本批具体主张和适用条件；逐条给中国官方发布机构、准确原文网址、日期和段落／页码定位。原创草稿、来源摘录和编辑判断分别标明。

机构身份、原文支持及图片／音视频许可分别说明。仅提交线索时不必自称已核，也不要求先写完整中英文文章。双语定稿由编辑从共同事实独立组织。图片等第三方材料优先给准确官方原页链接，未经许可不上传文件。

维护者审查后可以退回补证、拒绝或接收候选。公开PR被合并表示候选已收件，不代表正式资料采用或网站上线。没有自动采用或自动发布流程。正式数据以经审查、核验的 GitHub 资料版本为准。

Public submissions are visible to everyone. Use a title, an outline and the necessary content, with exact Chinese official sources and clear uncertainties. Proposals may be submitted in either language. Maintainers review evidence and rights before adoption; merging a proposal here does not update the authoritative dataset or deploy the website. Keep private information, credentials and unlicensed files out of submissions.
